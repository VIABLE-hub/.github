# VIABLE

Easy offline verification for enterprises. Secure and privacy preserving.

VIABLE develops digital credential infrastructure for issuing,
holding and verifying digital proofs. Our focus is practical enterprise workflows,
with a current commercial focus on employee IDs and travel entitlements.

## Explore our public prototypes

- [Credential issuer](https://github.com/VIABLE-hub/viable-issuer): prototype issuance service.
- [Credential verifier](https://github.com/VIABLE-hub/viable-verifier): prototype presentation verification service.

These repositories are prototypes. Supported formats, network requirements and
security limitations are documented in each repository. Research results and planned
QR, NFC and BLE capabilities should not be interpreted as universal device support
or a certification claim.
